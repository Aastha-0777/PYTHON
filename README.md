# Python

My Python learning journey, organized by topic. Each folder holds practice 
programs for one concept, starting from the basics and building up to 
small projects.

## Structure

| Folder | Topic |
|---|---|
| `Basics/` | Core syntax, variables, input and output |
| `Operators/` | Arithmetic, comparison, and logical operators |
| `ControlFlowStatements/` | Conditions and loops |
| `Strings/` | String handling and methods |
| `Lists/` | Lists and list operations |
| `Tuple/` | Tuples |
| `Set/` | Sets |
| `Dictionary/` | Dictionaries |
| `Functions/` | Defining and using functions |
| `Functions Revision/` | Revision exercises on functions |
| `Files/` | Reading and writing files |
| `Random Module/` | Programs using the `random` module |
| `Mini Projects/` | Small projects combining several concepts |

## Featured project

**Zombie Survival Game** (`Mini Projects/`): an interactive text-based game 
where you manage health, food, ammo, and money across multiple days. Built 
with the `random` module, dictionaries, functions, and `match-case`.
